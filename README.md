# CleanExpert74 — независимый демонстрационный сайт

Статический адаптивный сайт-визитка для демонстрации владельцу CleanExpert74 (Челябинск). **Проект не является официальным сайтом компании.** Никакие реальные заявки, фотографии и другие сведения на сервер не отправляются.

## Состав

- `index.html` — HTML всех разделов.
- `styles.css` — дизайн-система, мобильная адаптация и анимации.
- `app.js` — добавление/удаление услуг, количество, выбор загрязнений, локальный просмотр фото, копирование сформированного текста, меню и анимации.
- `config.js` — основные данные бизнеса и список услуг.
- `assets/` — 16 авторских SVG-файлов: иллюстрации первого экрана, услуг, этапов работы, орнамент, логотип-концепт, favicon и набор из 29 SVG-иконок.
- `robots.txt`, `vercel.json` — запрет поисковой индексации независимого демопроекта.

## Быстрый просмотр

Откройте `index.html` в браузере. При локальном `file://` некоторые браузеры ограничивают подключение внешних SVG-символов из `icons.svg`. Поэтому предпочтительнее открыть **`CleanExpert74_preview.html`** из поставки, в котором уже встроены CSS, JS и все SVG.

Или запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 8080
```

И откройте `http://localhost:8080`. Нет npm-зависимостей и сборки.

## Публикация на Vercel

1. Создайте GitHub-репозиторий `cleanexpert74-website`.
2. Распакуйте архив и положите **содержимое** папки проекта в корень репозитория (файл `index.html` должен быть в корне).
3. Коммит: `feat: launch CleanExpert74 website`.
4. В Vercel выберите **Add New → Project**, импортируйте репозиторий.
5. Выберите **Framework Preset: Other**. Build Command — пусто. Output Directory — `.` либо пусто.
6. Имя проекта: `cleanexpert74-demo`. Адрес `cleanexpert74-demo.vercel.app` появится только если доступен.
7. Проверьте сайт после развёртывания и мобильную версию.

**GitHub и Vercel не подключались автоматически.** Приведённые названия — рекомендации, а не ссылки на созданные проекты.

## Редактирование

- Контакты, сервисы и флаги деморежима меняются в `config.js`. Текстовые контакты в `index.html` также нужно синхронизировать, если номер изменится.
- Оформление: CSS-переменные в начале `styles.css`.
- Иллюстрации: SVG-файлы в `assets/`. Их можно заменять на фотографии только при наличии прав и согласия владельца.
- В футере находится отдельный блок **«Разработка сайта · @milmak11»**, ведущий на https://t.me/milmak11. После продажи сохранение подписи лучше согласовать с клиентом.

## Обработка заявок и фотографий

- Конфигуратор формирует *только текст запроса* и копирует его в буфер обмена. Отправка заявок отключена.
- Кнопка загрузки фото служит **исключительно локальному предпросмотру** на устройстве посетителя: фотография нигде не хранится и не прикрепляется к скопированному тексту.
- На сайте нет CRM, форм сбора телефона или сторонних аналитических скриптов.
- В `config.js` флаги `demoMode: true` и `allowSubmit: false`. Простое изменение флагов не подключает отправку: для неё необходимо после согласия владельца реализовать и протестировать отдельную интеграцию.

Проверить актуальность данных и услуг у владельца **обязательно**. В старых публикациях упоминалась работа с офисами и гостиницами, актуальность этого направления неизвестна.

На сайте намеренно **не размещены**: вымышленные цены, неподтверждённые гарантии, отзывы, статистика клиентов, коммерческие акции, имя владельца и спорные адреса. Вместо прайса используется подбор предметов и запрос на расчёт. Изображения являются тематическими векторными иллюстрациями и не выдают себя за фотографии выполненных работ.

## Передача официальной версии владельцу

1. Получите разрешение и подтвердите телефон, Telegram, VK, перечень услуг, цены, адрес, режим работы, юридические реквизиты, сроки и условия выезда.
2. Добавьте согласованные фотографии и реальные отзывы со ссылками на источники.
3. Реализуйте согласованный способ приёма заявок и при необходимости политику обработки персональных данных.
4. Подключите собственный домен и измените оформление демостатуса.
5. Только после официального согласования удалите запрет индексации из `index.html`, `robots.txt` и `vercel.json`.

## Проверки

Браузерные проверки автономного превью проведены в Chromium при ширинах 1440, 1024, 768, 390 и 360 пикселей: горизонтального переполнения и ошибок JavaScript не обнаружено. Проверены мобильное меню, добавление услуги из карточки, счётчики, выбор загрязнения, комментарий, копирование текста, сброс и раскрытие FAQ. SVG-файлы также проверяются XML-парсером при упаковке.
